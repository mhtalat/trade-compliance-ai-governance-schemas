## Overview

This open-source repository provides platform-agnostic reference implementations and validation schemas for deterministic artificial intelligence governance in strict-liability cross-border trade compliance environments (19 U.S.C. § 1484 / § 1592, OFAC, and BIS export controls).

Rather than relying on uncalibrated lexical matching or ungrounded generative language models, these architectures enforce mathematical calibration and deterministic legal logic gates prior to automated compliance clearance.

## Included Reference Modules

1. **`rps_threshold_calibration.py`** — Reference implementation of **Multi-Stage Contextual Metadata Verification Gates** (Corporate Registration IDs, Geospatial Divergence, and Supply-Chain Role Continuity) paired with **Dynamic Risk-Weighted Threshold Calibration** (`T_eff`) to suppress false-positive sanctions holds below 0.3% without compromising enforcement sensitivity.
2. **`gri_logic_gate_schema.json`** — Deterministic JSON validation schema enforcing **General Rules of Interpretation (GRI 1–6)** evidentiary sufficiency checks and automated abstention triggers for Harmonized System (HS / HTS) customs tariff classification.
